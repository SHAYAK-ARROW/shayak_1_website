Project 1: Rock Paper Scissors

How to open Terminal:
Windows: Press 'Windows Key', type cmd, and press Enter.
Android (Pydroid 3): Open app, tap 'three lines' menu, and select 'Terminal'.

Installation:
Type this in the terminal:
pip install rps-shayak

How to run:
Open Python and type:

rps.RPS.play_game()

Project 2: File Organizer

How to open Terminal in your folder:
Windows: Open your folder. Right-click on an empty space inside the folder while holding the Shift key, then select "Open PowerShell window here" or "Open in Terminal".
Alternatively: Click on the address bar, type cmd, and press Enter.
Android (Pydroid 3): Open the terminal and use cd command to navigate to your target folder.

Installation:
Type this in the terminal:
pip install file-organizer-shayak

How to run:
Method 1 (Command): Type
organize
in the terminal and press Enter.
Method 2 (Python Code): Open Python and type:
import file_organizer.organizer
file_organizer.organizer.run()
