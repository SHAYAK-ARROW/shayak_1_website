Hand-Cricket Game: Pattern-Based Bot
A project by SHAYAK-ARROW is now live on PyPI.

1. Install Python or Pydroid

  • PC: Download Python and add it to PATH.
  • Android: Download the 'Pydroid 3' app.

2. Open Terminal

  • Windows: Go to the Windows search box, type cmd or wt, and open it.
  • Android: Open the Pydroid app, click on the three lines (menu), then click on Terminal from the run section.

3. Install the Game

Type the following command and press Enter:

pip install rps-shayak

4. Run the Game

For Windows: Type python, press Enter, then paste the code below.
For Android: Paste the code in the main editor and press the Play button.

import rps.RPS  
rps.RPS.play_game()

Please ensure you don't add any extra spaces. .

Enjoy the game! Contact me if you face any issues.
